# 영천시 화재 대응 취약도 시각화 대시보드

### 🔗 배포 주소
👉 [https://han-gyumin.shinyapps.io/yc_project/](https://han-gyumin.shinyapps.io/yc_project/)

---

## 📌 프로젝트 개요

본 프로젝트는 **영천시 화재 발생 시** 지역별 취약도와 대응 인프라 현황을 시각화한 대시보드입니다.  
공공데이터를 기반으로 **읍면동 단위의 위험도 분석**, **소방 인프라 및 대피소 현황** 등을 종합하여  
화재 대응 시 취약 지역을 직관적으로 파악할 수 있도록 설계하였습니다.

---

## 🔍 주요 기능

- **지역별 화재 취약도 분석:**  
  읍면동 단위 위험도 점수 시각화 및 범례 제공
- **소방 인프라 분포 시각화:**  
  소방서, 소방차 위치 데이터 표시
- **대피소 및 소화전 분포 확인:**  
  위험도 대비 인프라 분포 격차 확인
- **위험도 기반 색상 시각화:**  
  위험도에 따라 색상 단계별 표시
- **선택 지역 필터링 기능:**  
  원하는 읍면동만 선택하여 지도 표시 가능
